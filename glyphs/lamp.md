

# [`⍝`](https://answerdotai.github.io/basedpl/glyphs/lamp.html) — Comment

Comment. Keys: `Alt-o c`. Hanzi: `注`

[`⍝`](https://answerdotai.github.io/basedpl/glyphs/lamp.html) comments
to end of line.

``` text
v←ι10ₓ    ⍝ first ten integers
+/v       ⍝ sum
```

Inside character and string literals it is an ordinary character.

``` bpl
≢"a⍝b"             ⍝ 3ₓ
```
