

# [`⊢`](https://answerdotai.github.io/basedpl/glyphs/right-tack.html) — Same / Right

Function. Keys: `Alt-'`. Hanzi: `右`. Ranks:
[`∞`](https://answerdotai.github.io/basedpl/glyphs/infinity.html)
monadic, `∞ ∞` dyadic

`⊢Y` and `X⊢Y` return `Y`.

``` bpl
⊢1 2               ⍝ 1 2
1 2⊢3 4            ⍝ 3 4
```

Both arguments are evaluated.

## Inverse

`⊢⁻` is
[`⊢`](https://answerdotai.github.io/basedpl/glyphs/right-tack.html).

``` bpl
3⊢⁻5   ⍝ 5
```
