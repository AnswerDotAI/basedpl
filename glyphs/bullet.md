

# [`•`](https://answerdotai.github.io/basedpl/glyphs/bullet.html) — System

System. Keys: `Alt-y`. Hanzi: `系`

[`•`](https://answerdotai.github.io/basedpl/glyphs/bullet.html) starts a
[system function](../system-functions.qmd) name. Names are
case-insensitive.

``` bpl
•c "AbC"           ⍝ "abc"
```
