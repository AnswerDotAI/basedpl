

# [`⍶`](https://answerdotai.github.io/basedpl/glyphs/alpha-underbar.html) — Left operand

Argument. Keys: `Alt-Minus a`. Hanzi: `丙`

In a defined operator,
[`⍶`](https://answerdotai.github.io/basedpl/glyphs/alpha-underbar.html)
denotes its left operand: function or subject.

``` bpl
apply←{⍶ ω} ◇ -apply 3 ⍝ ¯3
add←{⍶+ω} ◇ 10 add 3 ⍝ 13
```

[`α`](https://answerdotai.github.io/basedpl/glyphs/alpha.html) and
[`ω`](https://answerdotai.github.io/basedpl/glyphs/omega.html) remain
the derived function’s arguments.
