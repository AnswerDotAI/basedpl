

# `•storage` — Storage

`•storage Y` names the storage that holds the items of `Y`: `"boolean"`,
`"integer"`, `"float64"`, `"float32"`, `"float16"`, `"complex"`,
`"character"` or `"mixed"`. An atom gives its own kind, which can also
be `"rational"` or `"function"`. Compact storage holds items of one
kind. `"integer"` covers integers of every width. Mixed storage keeps
each item’s kind. Boxed display marks the same storage on its bottom
edge. [Storage](../numbers.qmd#storage) describes each storage.
