

# `•nc` — Name class

`•nc names` gives the class of each name: `¯1` invalid, `0` undefined,
`2` value, `3` function, `4` operator. A function glyph or a system
name, such as
[`+`](https://answerdotai.github.io/basedpl/glyphs/plus.html) or
`•json`, has class `3`. A character vector is one name.
[Introspection](../introspection.ipynb) has examples.
